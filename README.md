# music-distribution-lib

This library provides a set of modules for managing music distribution, including domain models, services, and repositories.

## Modules

The library is currently structured into the following modules:

* **domain:** This module contains the core domain models representing entities involved in music distribution.
* **repositories:** This module defines interfaces and implementations for data access related to music distribution entities.
* **services:** This module contains business logic and use cases for music distribution operations.
